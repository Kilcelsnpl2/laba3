Цель
Освоение базового синтаксиса C++ и математических вычислений на примере расчёта коэффициента сопротивления плоскопараллельной насадки химической колонны.

Описание
Программа вычисляет коэффициент сопротивления ξ и число Рейнольдса Re для плоскопараллельной насадки при различных скоростях газа. Расчёт выполняется по двум формулам в зависимости от значения Re.

Исходные данные
Ширина каналов насадки: ℓ = 15 мм
Плотность газа: ρ = 0.0011 г/см³
Динамическая вязкость: μ = 1.8·10⁻⁴ г/(см·с)
Скорости газа: W = 1, 2, 5, 10, 20 м/с
